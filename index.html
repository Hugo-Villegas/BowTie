⬡ Causas / Amenazas Activa las pastillas P para asignar barreras a cada causa
Cada causa puede tener una o más barreras preventivas. Activa las pastillas P1, P2… que aplican. Una misma barrera puede cubrir varias causas.
    🛡 Barreras Preventivas — P1, P2… Factor de escalamiento + control de ese factor
    Factor de escalamiento: condición que debilita o anula la barrera.
    Control del factor: acción que mantiene la barrera eficaz frente a ese factor.
      ⚡ Consecuencias Activa las pastillas M para asignar barreras a cada consecuencia
      Cada consecuencia puede tener una o más barreras mitigadoras. Activa las pastillas M1, M2… que aplican.
        🔧 Barreras Mitigadoras — M1, M2… Factor de escalamiento + control de ese factor
        Factor de escalamiento: condición que debilita o anula la barrera.
        Control del factor: acción que mantiene la barrera eficaz frente a ese factor.
